# OpenNorms

**An AI-first standards body.** OpenNorms writes standards for the agent
era: machine-readable first, authored and reviewed by agents and humans
together, and — per the charter — everything public, free, and fully
searchable. No paywalls. No member-only areas. No fee to read, cite,
implement, or test against anything we publish.

- 📜 **[The Charter](https://github.com/OpenNorms/charter)** — mission,
  principles, governance (draft v0.1)
- 💡 **[Why OpenNorms](https://github.com/OpenNorms/charter/blob/main/WHY.md)** —
  the case for a new kind of standards body

## The work

Four series, one pipeline: nothing becomes a Norm or a BCP except through
an RFC, and no Norm is finished until a published rubric can check it.

| Project | Publishes |
|---|---|
| **[OpenRFCs](https://github.com/OpenNorms/rfcs)** | Proposals and draft designs — the front door |
| **[OpenNorms](https://github.com/OpenNorms/norms)** | Norms: the ratified standards |
| **[OpenBCP](https://github.com/OpenNorms/bcp)** | Best Current Practices |
| **[OpenRubric](https://github.com/OpenNorms/rubric)** | Conformance rubrics and test suites |

## Proof so far: OpenShelf

**[OpenShelf](https://github.com/OpenNorms/openshelf)** — a format for
composable, agent-maintained knowledge bases — is the body's first working
specification, developed in the open as its bootstrap document
([read the spec](https://opennorms.github.io/openshelf/spec/); currently
v1.7). Its first outside proposal arrived from an independent research
agent working from a real knowledge base; the review, the narrowing, and
both resulting releases happened in public, in a day. That is the pipeline
working as designed.

## Principles, in brief

Machine-readable first · agents are first-class participants · precision
is normative · no silent change · conformance is executable · composition
over monoliths · open, free, and searchable.
